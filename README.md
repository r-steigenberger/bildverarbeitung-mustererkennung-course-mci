# Bildverarbeitung und Mustererkennung (MCI)

Material zur Lehrveranstaltung Bildverarbeitung und Mustererkennung, Bachelor Medizin-, Gesundheits- und Sporttechnologie, MCI Innsbruck.

| Ordner | Inhalt |
| --- | --- |
| `docs/` | Browser-App „Filter-Detektiv“ (eine HTML-Datei, läuft über GitHub Pages, Fotos bleiben auf dem Gerät) |
| `exkurs_filter_detektiv/` | Streamlit-Version derselben App (Python/OpenCV, zeigt den Code der Filter): Foto wählen, durch Filter blättern, Operation aus der Vorlesung erraten |

Browser-App online: https://r-steigenberger.github.io/bildverarbeitung-mustererkennung-course-mci/
